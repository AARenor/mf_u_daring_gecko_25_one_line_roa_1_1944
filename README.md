# One-line gadget roast

A tiny program that writes one short text for make.fun's bounty `u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`, whose brief is a single original line, up to 200 characters, roasting a gadget or app used every day; main.py keeps that line as one string constant, asserts it is between 1 and 280 characters, creates the output folder, writes `entry.txt` there as UTF-8 with no trailing newline, and prints the character count to stderr.
